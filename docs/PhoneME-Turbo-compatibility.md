## Khác biệt phần cứng và hệ điều hành



`PhoneME-Turbo.apk` dành cho thiết bị Android đời thấp hơn, sử dụng cấu hình heap 32 MB và ABI armeabi. `PhoneME-Turbo-nHD.apk` dành cho thiết bị Android mới hơn, sử dụng cấu hình heap 64 MB và lớp hiển thị phù hợp màn hình nHD.



Cả hai bản giữ package `be.preuveneers.phoneme.fpmidp`, hỗ trợ game Java ME qua file JAR, giao diện lưới danh sách game, nhập Unicode tiếng Việt, bàn phím ảo SIP và audio ổn định. Việc lựa chọn bản nào nên dựa vào phiên bản Android và độ phân giải thiết bị.



## Lưu ý cài đặt



Android có thể yêu cầu cho phép cài ứng dụng từ nguồn phù hợp với thiết bị. Nếu APK cũ đang được cài, hãy gỡ bản cũ trước khi cài bản mới nếu hệ thống báo xung đột chữ ký hoặc gói ứng dụng.
