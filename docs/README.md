# Kỹ thuật

Thư mục này chứa các báo cáo về phạm vi patch và kiểm tra đầu ra. Báo cáo mô tả các thay đổi ở mức có thể tái hiện, nhưng không chứa keystore, mật khẩu, log cá nhân hoặc toàn bộ cây giải mã PhoneME.

Các offset native chỉ áp dụng cho đúng nền ELF đã kiểm tra trong dự án. Không nên áp dụng trực tiếp lên một APK khác nếu chưa xác minh kích thước chunk, branch site và vùng helper.
