# PhoneME Turbo 1.2.1

PhoneME Turbo 1.2.1 là bản cập nhật tiếp theo của trình giả lập Java ME dành cho Android.

## Tệp phát hành

- [`PhoneME-Turbo-1.2.1.apk`](PhoneME-Turbo-1.2.1.apk) — APK đã ký, dùng để cài đặt và phân phối.
- [`CHANGELOG.md`](CHANGELOG.md) — các thay đổi so với PhoneME Turbo 1.2.0.
- [`SHA256SUMS.txt`](SHA256SUMS.txt) — checksum SHA-256 của APK và tài liệu release.

Gói public **chỉ giữ APK release-signed**; bản unsigned không được đưa vào repository hoặc GitHub Release vì không cần thiết cho người dùng cuối.

## Thông tin phiên bản và chữ ký

- Version name: `1.2.1`
- Android version code: `26`
- Package: `be.preuveneers.phoneme.fpmidp`
- Target SDK: `22`
- Native ABI: `armeabi`
- APK sử dụng cùng certificate phát hành với PhoneME Turbo 1.2.0-15 để hỗ trợ cập nhật giữa các bản cùng certificate.
- Chữ ký APK và tính toàn vẹn ZIP đã được kiểm tra. Việc hiển thị glyph mới trên thiết bị thực tế chưa được kiểm tra trong môi trường này.

## Cài đặt

Nếu Android báo xung đột chữ ký với bản cũ, hãy sao lưu dữ liệu rồi gỡ bản cũ trước khi cài. Việc gỡ ứng dụng có thể xóa dữ liệu private của app.
