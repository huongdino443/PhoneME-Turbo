# Release artifacts

Các APK phát hành không được commit trực tiếp vào lịch sử Git để giữ repository gọn và dễ clone. Hai file APK stable 1.1.2 được đính kèm trong [GitHub Release v1.1.2](https://github.com/huongdino443/PhoneME-Turbo/releases/tag/v1.1.2), kèm SHA-256 trong `README.md` và `CHANGELOG.md`.

| Bản | File |
|---|---|
| PhoneME-Turbo | `PhoneME-Turbo-1.1.2.apk` |
| PhoneME-Turbo(nHD) | `PhoneME-Turbo-nHD-1.1.2.apk` |

Không đặt keystore hoặc mật khẩu ký APK trong thư mục này. Nếu tự build lại, hãy dùng keystore riêng và không commit nó.
