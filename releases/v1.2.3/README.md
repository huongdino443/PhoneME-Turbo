# PhoneME Turbo 1.2.3

Bản phát hành gồm hai APK release-signed của PhoneME Turbo. Bản unsigned không được phân phối.

- `PhoneME-Turbo-1.2.3.apk` — bản tiêu chuẩn, minimum SDK 18, version code 28.
- `PhoneME-Turbo-1.2.3-api8.apk` — bản API 8 cho Android 2.2 trở lên, minimum SDK 8, version code 45.

Cả hai APK dùng target SDK 22, native ABI `armeabi` và cùng certificate phát hành PhoneME Turbo.
