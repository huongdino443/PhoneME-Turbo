# PhoneME Turbo 1.2.0 — release bundle

Release date: 2026-09-29

This archive contains the signed 1.2.0 APK and the selected release materials
available in the workspace. The APK is the current **PhoneME Turbo** release,
developed from the historical 1.1.2 line through v337–v340; it is not
distributed as a separate nHD variant. The APK is based on the user-approved v340 build;
the 1.2.0 change is a version metadata update plus signing with the previously
used PhoneME Turbo release certificate.

## Important install/update note

The canonical 1.1.2 reference APK in the workspace uses a different signing
certificate (`86:C7:1B:35:E9:E0:A0:51:F4:A6:7A:AD:46:B7:79:37:D8:44:18:B0:E6:DF:51:78:C7:A3:03:A0:76:01:7F:61`). Android will not install this 1.2.0 APK as an
in-place update over an APK signed by that certificate. Back up anything
important, uninstall that older APK, then install 1.2.0. App-private data may be
removed by uninstalling. Builds signed with the 1.2.0 release certificate can
update one another normally.

## Verification status

The v340 baseline was the user-approved build. The 1.2.0 APK was generated by
changing only Android version metadata before release signing; its DEX,
resources, native library, and other non-manifest payloads were compared with
the v340 baseline. ZIP integrity, APK signature, package identity, version
metadata, and release-certificate fingerprint were checked. This packaging
step is not a new physical-device install test.
