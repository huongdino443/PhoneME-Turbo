# PhoneME Turbo 1.2.2

PhoneME Turbo 1.2.2 được phát hành với hai APK cùng dòng phiên bản, phù hợp với các nhóm thiết bị Android khác nhau.

## Tệp phát hành

- [`PhoneME-Turbo-1.2.2.apk`](PhoneME-Turbo-1.2.2.apk) — bản tiêu chuẩn, minimum SDK 18.
- [`PhoneME-Turbo-1.2.2-api8.apk`](PhoneME-Turbo-1.2.2-api8.apk) — bản tương thích Android API 8 / Android 2.2, minimum SDK 8.
- [`CHANGELOG.md`](CHANGELOG.md) — các thay đổi của bản 1.2.2.
- [`SHA256SUMS.txt`](SHA256SUMS.txt) — checksum SHA-256 của hai APK và tài liệu release.

Repository và GitHub Release chỉ phân phối APK release-signed; bản unsigned không được đưa vào.

## Thông tin phiên bản

| Biến thể | Version name | Version code | Minimum SDK | Target SDK | ABI |
|---|---:|---:|---:|---:|---|
| Tiêu chuẩn | `1.2.2` | `27` | `18` | `22` | `armeabi` |
| API 8 | `1.2.2-api8` | `44` | `8` | `22` | `armeabi` |

Hai APK dùng cùng certificate phát hành PhoneME Turbo. Khi Android báo xung đột chữ ký, hãy sao lưu dữ liệu rồi gỡ bản cũ trước khi cài.
