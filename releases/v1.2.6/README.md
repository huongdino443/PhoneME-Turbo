# PhoneME Turbo 1.2.6 release package

PhoneME Turbo 1.2.6 gồm hai APK signed: bản tiêu chuẩn cho Android API 18 trở lên và bản API 8 cho Android 2.2 trở lên.

## Files

- `PhoneME-Turbo-1.2.6.apk` — bản tiêu chuẩn, minimum SDK 18, version code 35.
- `PhoneME-Turbo-1.2.6-api8.apk` — bản API 8, minimum SDK 8, version code 49.
- `CHANGELOG.md` — các thay đổi so với v1.2.5.
- `SHA256SUMS.txt` — checksum SHA-256 của các file release.

Hai APK sử dụng certificate phát hành PhoneME Turbo. Bản unsigned không được phân phối.

## Chọn APK

- `PhoneME-Turbo-1.2.6.apk`: bản tiêu chuẩn, dành cho thiết bị Android API 18 trở lên.
- `PhoneME-Turbo-1.2.6-api8.apk`: dành cho Android API 8 / Android 2.2, phù hợp hơn với Android đời thấp hoặc thiết bị cấu hình thấp.

***Người dùng nên ưu tiên chọn bản PhoneME Turbo 1.2.6 tiêu chuẩn; chỉ chọn bản API 8 khi thiết bị chạy Android đời thấp hoặc không tương thích với bản tiêu chuẩn.***
