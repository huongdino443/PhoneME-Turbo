# PhoneME Turbo 1.2.5 release package

PhoneME Turbo 1.2.5 gồm hai APK signed: bản tiêu chuẩn cho Android API 18 trở lên và bản API 8 cho Android 2.2 trở lên.

## Files

- `PhoneME-Turbo-1.2.5.apk` — bản tiêu chuẩn, minimum SDK 18, version code 34.
- `PhoneME-Turbo-1.2.5-api8.apk` — bản API 8, minimum SDK 8, version code 48.
- `CHANGELOG.md` — các thay đổi so với v1.2.4.
- `SHA256SUMS.txt` — checksum SHA-256 của các file release.

Hai APK sử dụng certificate phát hành PhoneME Turbo. Bản unsigned không được phân phối.
